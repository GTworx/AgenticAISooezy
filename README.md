# Agentic AI Sooezy
## Welcome to the Agentic AI Sooezy GitHub Repo

A collection of agentic AI projects, multi-agent pipelines, and Claude Code skills.

---

## Projects

| Folder | Description |
|---|---|
| [Concerts](Concerts/) | **[BeatSync](https://beatsync.sooezy.academy)** — A browser-based concert discovery dashboard. Browse and filter live events by city (Stockholm, Berlin, London, Paris), genre, and price range. |
| [CulirnarySearch](CulirnarySearch/) | **[CulinarySearch](https://culinarysearch.sooezy.academy)** — A 4-agent pipeline (Scout → Ranker → Logistics → Orchestrator) that takes a location and dining preferences and produces a personalized, logistics-enriched restaurant guide within a 5 km radius. |
| [dnd-playbook](dnd-playbook/) | **[D&D Playbook](https://dnd.sooezy.academy)** — A Claude Code skill that launches an interactive D&D 5e dashboard in the browser. Covers rules, classes, spells, monsters, races, equipment, a dice roller, and a quick character sheet builder — all backed by the public D&D 5e API. |
| [EverydayAI](EverydayAI/) | **EverydayAI** — A 12-agent sequential pipeline that discovers, ranks, and packages AI productivity tools for office workers. Outputs a weekly Mon–Fri learning curriculum, blog articles, how-to guides, quizzes, and social media copy. |
| [RestaurantSearch](RestaurantSearch/) | **RestaurantSearch** — Multi-agent restaurant search pipeline (shares the EverydayAI schema). Discovers and evaluates local dining options using a structured agent workflow. |
| [yahoo-most-active-stocks](yahoo-most-active-stocks/) | **Yahoo Most Active Stocks** — A Claude Code skill that scrapes Yahoo Finance for the day's most active stocks and saves the results as a formatted Markdown table. |
